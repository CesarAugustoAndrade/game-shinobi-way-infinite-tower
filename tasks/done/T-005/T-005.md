## Spec

### Must exist when done

1. **Mode runtime state machine (pure):**  
   States: `OFF` (ready | cooling) → `ACTIVATION` (pay AP + activation cost; **charges = maxCharges**) → `ON` (upkeep each turn, routes, charges) → `FIN` (payoff / manual off / 0 charges / upkeep fail / family replace / finisher) → `COOLDOWN` → `READY`.  
   Immutable transitions; active Modes live on combat (or actor) state, **not** only as anonymous buffs.

2. **Charges:**  
   Do not decay with time. Spend on **attempt** when a skill declares charge cost (API: `trySpendCharges(modeId, n)`). Never exceed `maxCharges`. 0 charges → end Mode → cooldown per definition.

3. **Upkeep:**  
   Ordered by `modeUpkeepPriority[]` (or insertion order if empty). Pay CP/HP **per mode** if affordable; failure ends that Mode and starts its cooldown; **later modes still attempt**.  
   **HP floor:** if HP upkeep would drop below 1 HP → Mode off, HP stays ≥ 1.  
   Upkeep payment must be usable **before** same-turn regen (align with T-002; pure function order testable without full clock).

4. **Family rules (pure):**  
   - Multiple Modes ON if different `modeFamily`.  
   - Same family: no dual ON.  
   - **Ascenso** (higher stage same family, e.g. Gate/Curse): pay full AP + **difference** of activation resource; charges remaining **+1** capped at new max; **no downgrade** API.  
   - **Lateral** (e.g. Sharingan 2T↔3T): full activation cost; **transfer** charges without refill or +1; previous Mode enters cooldown.  
   - **Manual off:** re-play Mode card while ON → AP full, **no** activation resource cost, start cooldown (function exists even if live UI later).

5. **Forced off v1:**  
   Explicit charge drain can end an enemy Mode; document that Stun/Silence **do not** end Modes (helper ignores stun flags).

6. **v1 Mode definitions (data):**  
   Register SOUL §8 table entries (ids/families/stages/maxCharges/activation/upkeep/cooldown numbers) as data — at least the eight named Modes as `ModeDefinition` fixtures/constants. Full Attack enhancement routes may be stubs (`enhancements[]` / `endClauses[]` typed arrays) as long as machine + costs + charges work.

7. **Encounter reset:**  
   Clear active Modes/charges/cooldowns on combat start (hook compatible with T-002 frontier).
