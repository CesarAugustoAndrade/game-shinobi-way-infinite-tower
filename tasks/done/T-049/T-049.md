## Spec

### Must exist when done

1. **Authoring (`kunai_throw`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 1**, **CP 0**, **CD 1**, HP 0.
   - `baseDamage: 7`; single hit; `attackMethod: RANGED`; `allowedRanges: [MEDIUM, LONG]` (not CLOSE).
   - Tags: `TOOL`, `WEAPON` (+ PHYSICAL as convention).
   - Next-draw contract: on impact (≥1 hit), enqueue **TOOL tag weight +1** for one draw (see §3).
   - Honest description matching catalog.

2. **`resolveSkill` SIDE**
   - Pay costs; full hit → `damageDealt === 7` under test ports.
   - Range gate: illegal at CLOSE (reject or existing playability — prefer validate fail if range CLOSE when snapshot/range checked).
   - **≥1 hit:** enqueue TOOL +1 pending weight; **full miss:** no enqueue.
   - No Bleed (Slash owns Bleed); no Mode; no band move.

3. **TOOL tag weight bag**
   - Extend pending support-weight bag with a tag entry, e.g. `{ kind: 'tag', tag: SkillTag.TOOL, delta: 1 }` **or** equivalent field on skill `nextDrawTagBonus: { tag: TOOL, delta: 1 }` applied only after hit.
   - `effectiveWeight`: add delta when `skill.tags` includes TOOL while bag entry active.
   - One-shot: consumed with next draw bag clear (same lifetime as T-016).
   - Non-TOOL skills unchanged; TOOL skills +1 regardless of role (SIDE or ATTACK with TOOL tag).
