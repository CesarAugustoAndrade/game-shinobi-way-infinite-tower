## Context

Hyuga Mode, CP marks, Lions, and 64 Palms exist. Gentle Fist is the **Main-shaped** single-hit ATTACK that always deals 12, gains **Byakugan +40% for 1 charge**, and on hit may **spend up to two** enemy `chakra_point` stacks for **+10% each** and **4 enemy CP drain each** — still a legacy drain-% card with no role.

## Spec

### Must exist when done

1. **Authoring (`gentle_fist`)**
   - `cardRole: CardRole.ATTACK`.
   - Costs: **AP 2**, **CP 4**, **CD 2**, HP 0; `baseDamage: 12`; single hit; **CLOSE** (`allowedRanges: [CLOSE]`).
   - `modeInteraction` (Byakugan):
     - `modeId: 'byakugan'`, family HYUGA.
     - `consumeCharges: 1`, `damageMultBonus: 0.4` when Mode **ON** and charge spend succeeds.
     - Soft base: play **allowed** without Byakugan at base 12 (Main without setup remains viable) — do **not** hard-reject like Peacock unless catalog hard-requires (it does not).
   - Impact CP contract (authoring field and/or skill-id branch — document):
     - On **≥1 hit**, consume **min(2, enemy chakra_point stacks)** only (not all).
     - Per stack consumed: **+10%** damage mult (stacking with Mode +40% in declared order — prefer Mode mult then CP mult, or single combined factor locked in test: e.g. Byakugan+2CP → 12 × 1.4 × 1.2 or additive 0.4+0.2 — **prefer multiplicative Mode then CP: floor(12 * 1.4 * (1 + 0.1 * n))**).
     - Per stack consumed: **drain 4** enemy chakra (flat). Prefer optional `enemyChakra` (or `enemyPools.chakra`) on `ResolveSkillState`; floor at 0.
   - Remove primary identity of `CHAKRA_DRAIN` value 20% effect.
   - Honest description matching catalog. Do **not** auto-assign `mainAttackId` here.
   - Clan/stats may remain Hyuga/ACC.

2. **`resolveSkill` ATTACK**
   - Validate+commit; resolve hit under ports.
   - **No Byakugan:** damage 12 (test ports); no charge spend; if hits and CP present, still allow **up to 2 CP** consume +10%/stack + drain (catalog says “puede consumir… al impactar” without requiring Mode for CP part — if ambiguous, **CP consume only when Byakugan ON** is acceptable if documented; **prefer CP on impact independent of Mode** to match “puede”).
   - **Byakugan ON charges ≥1:** spend 1 charge; +40% Mode mult; then CP impact rules.
   - **Full miss:** no CP consume; no drain; charge: prefer spend at **attempt** if Mode path uses attempt spend (consistent with other Mode ATTACKs that spend at attempt) — lock: **charge at attempt** when Mode ON (even on miss), matching Chidori/Fireball style; document if charge only on hit instead.
   - Prefer **charge at attempt** + **CP only on ≥1 hit** (SOUL impact vs attempt split).

3. **Partial CP consume helper**
   - Must not use consume-all for this skill.
   - Remaining CP stacks above 2 stay on enemy.
   - 0 CP stacks: no extra mult, no drain.
