## Spec

### Must exist when done

1. **Authoring (`shuriken`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 1**, **CP 0**, **CD 1**, HP 0.
   - `baseDamage: 11`; single hit; RANGED; `allowedRanges: [MEDIUM, LONG]` (catalog MEDIUM · LONG).
   - Tags: TOOL / WEAPON / PHYSICAL as available.
   - `markEffects`: self mark id **`aim`**, duration **2**, `consume: ATTEMPT`, stacks/metadata **+1 ACC** (honest integer; family STAT). Prefer `targetActor: 'self'`.
   - Crit packaging: may keep a modest critBonus only if it does not replace Aim; **primary identity** is 11 + Aim — remove any implication that critBonus is the SOUL setup. Prefer drop or leave ≤ existing if tests do not require it.
   - Honest description: 11 dmg M/L; Aim 2 → next ATTACK +1 ACC.

2. **`resolveSkill` SIDE**
   - Pay costs; full hit → `damageDealt === 11` under test ports.
   - On **≥1 hit**: plant `aim` duration 2 on player.
   - On **full miss**: no plant; damage 0.
   - No Mode; no band move; no Bleed.

3. **Next ATTACK +1 ACC**
   - When resolving `cardRole === ATTACK`, if `aim` is among own ATTEMPT marks spent: apply **+1 ACC** contribution in pure path (mirror T-043 DEX rule):
     - Preferred: if `scalingStat === ACCURACY`, add **`scalingPerPoint * 1`** to damage under test ports; else apply **+1** flat damage **or** document equivalent — **lock one** in AC3.
   - SIDE plays do not consume Aim for the +1 ACC payoff (only ATTACK spends it).
   - Full miss ATTACK: consume at attempt per SOUL; no damage bonus.
   - Without `aim`, baseline unchanged.
