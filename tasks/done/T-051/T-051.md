   - Costs: **AP 2**, **CP 0**, **CD 2**, HP 0.
   - `baseDamage: 14`; single hit; CLOSE; melee; TAIJUTSU/PHYSICAL tags as available.
   - On-impact contract: enemy **−1 SPEED** for **duration 2** (integer). Prefer:
     - enemy mark id `spd_down` (or `leaf_whirlwind_spd`) stacks **1** meaning −1 SPD, duration 2, family STAT; **or**

2. **`resolveSkill` ATTACK**
   - Pay costs; full hit → `damageDealt === 14` under test ports.

   - No Mode; no Feint interaction required.

   - Live SPD application to enemy turn order may remain partial; AC requires **state plant** at minimum. Optional: pure helper reading effective enemy SPEED for tests if already trivial.
