## Spec

### Must exist when done

1. **Authoring (`ice_mirrors`)**
   - `cardRole: CardRole.ATTACK`.
   - Costs: **AP 3**, **CP 7**, **CD 4**, HP 0 (catalog; fix AP 2→3).
   - `baseDamage: 4`; `hitCount: 4` (4×4).
   - ANY range (no restrictive `allowedRanges`, or all three bands if project requires explicit list).
   - Conditional stun: **40%** Stun duration **1** only if `hitsLanded >= 2`. Prefer `impactStun: { chance: 0.4, duration: 1, minHitsLanded: 2 }` (extend `ImpactStunSpec` with optional min hits; default 1 preserves existing skills).
   - Tags: NINJUTSU / WATER / MULTI_HIT / CONTROL as available.
   - Remove primary single-hit base 15 + effects STUN 0.5 + PIERCING-as-identity if not catalog (catalog does not require piercing).
   - Honest description: 4×4 ANY; if ≥2 hits, 40% Stun 1.

2. **`resolveSkill` ATTACK**
   - Pay AP3/CP7/CD; four independent hit rolls.
   - hitsLanded 0–1: **no** stun roll (or roll skipped).
   - hitsLanded ≥ 2: one stun roll at 0.4 → enemy STUN 1 on success (same buff model as other impactStun).
   - Damage under hit port scales with landed hits × 4 baseline each (document fixture total).
   - No Mode require; no Terrain/Heat.

3. **Compose**
   - Extend `resolveImpactStun` to honor `minHitsLanded` (default 1) using already-computed `hitsLanded`.
   - Do not invent a second stun pipeline.
