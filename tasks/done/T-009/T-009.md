## Context

Live combat is moving to SOUL physics via T-002–T-007. Auto-combat and AI must not remain a DPS-only shadow ruleset. This task binds AI selection and sim execution to the **same resolve/board/Mode/Mark contracts** (or explicit ports) and adds **metric hooks** for balance.

## Spec

### Must exist when done

1. **Enemy AI (SOUL §15):**  
   - Continues **direct** skill selection from available enemy skills (no player-style weighted hand, no Main Attack config).  
   - Selection context includes range, AP, cooldowns, and — when present — Mode/Mark/setup state (fixtures if motor not merged).  
   - Prefer scoring that values **future state / setup pressure**, not raw damage alone (at least one non-damage term: e.g. apply mark, spend/gain setup, self Mode upkeep risk).  
   - Elite/Boss: keep telegraph/`intendedSkill` path; Sharingan “read intent” consumes **existing** intention fields only (no new secret AI).

2. **Simulator parity:**  
   - Player auto path and enemy path must call the **same pure resolve/hit/Mode/Mark helpers** as live combat once available (T-007), not a private damage-only fork for core commits.  
   - Remove or stop using **normative** dual deck draw inside sim when T-003 lands; until then, document adapter but AC requires sim player actions go through shared resolve test double or real `resolveSkill`.  
   - FREE_FIRST in sim: chakra only (align T-006).  
   - Cooldown-reset style effects: reset CD / Modes **off** only; do not activate Mode or refill charges (pure helper + test).

3. **Artifacts:**  
   On-hit artifact procs **once per card** if ≥1 hit (document + test with fixture), consistent with multi-hit SOUL rules.

4. **Metrics hooks (pure or R3 collector):**  
   Emit/record at least these counters/events from a sim run (names flexible):  
   `setupCompletion`, `deathDuringSetup`, `enhancedVsBase`, `modeLifetime`, `deadCardRate`, `weightInfluence`, `rangeReactions`, `payoffShare`, `upkeepFailure`.  
   Empty/zero when features absent is OK if hooks exist and tests prove increments under fixtures.

- [x] Do not invent AI tactics outside SOUL (no secret weighted enemy hand)
