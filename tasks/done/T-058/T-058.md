## Spec

### Must exist when done

1. **Authoring (`senbon`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 1**, **CP 0**, **CD 1**, HP 0.
   - `baseDamage: 7`; single hit; RANGED; `allowedRanges: [MEDIUM, LONG]`.
   - Tags: TOOL / WEAPON / PHYSICAL / CONTROL as available.
   - Silence contract: **35%** chance, **Silence duration 1** on enemy when impact lands. Prefer `effects` SILENCE 0.35×1 **and** resolve honors it, or `impactSilence: { chance: 0.35, duration: 1 }` — **lock one**.
   - Honest description: 7 dmg M/L; 35% Silence 1 on hit.

2. **`resolveSkill` SIDE damage**
   - Full hit → `damageDealt === 7` under ports.
   - Full miss → damage 0; **no** Silence.

3. **Impact Silence 35%**
   - On **≥1 hit**, injectible `rng` once: if `rng() < 0.35`, append enemy SILENCE buff duration **1** (reuse Sealing Tag silence buff shape).
   - If `rng() >= 0.35`, no Silence.
   - Silence must **not** end enemy Modes (existing Mode rules; no Mode board mutation).
   - No PUSH; no Bleed; no Mode.
