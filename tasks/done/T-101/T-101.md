   - Consume: on ≥1 hit, remove enemy **`coffined`** only (`consume: true` for that mark). **Must not** strip STUN buffs as part of this skill’s consume.
   - Tags: NINJUTSU / EARTH as available.
   - Honest description: 18 M/L; +50% Setup vs Coffined/Stunned; consumes Coffined on hit, not Stun.
   - Remove primary “+100% below 25% HP” identity.

2. **`resolveSkill` ATTACK**
   - Pay AP3/CP6/CD.
   - Baseline (no Coffined, no Stun): damage **18** under hit port.
   - If enemy `coffined` **or** enemy STUN present: Setup mult **1.5** → `floor(18 * 1.5)` (or same floor style as other Setup mults); still once per card.

   - Miss: no Coffined consume; no damage.
   - No Terrain/Heat; no Mode require.
