## Spec

### Must exist when done

1. **Pure allowlisted mapper + applicator**
   - e.g. `primaryDeltasFromStatMarks(marks, target: CombatActor): Partial<PrimaryAttributes>` and/or `applyStatMarksToPrimaryStats(base, marks, target)`.
   - **v1 allowlist (signed by stacks):**
     | mark id | primary key | sign |
     |---------|-------------|------|
     | `spd_down` | `speed` | −stacks |
     | `adamantine_spd` | `speed` | −stacks |
     | `air_acc_down` | `accuracy` | −stacks |
     | `blinded` | `accuracy` | −stacks |
     | `expansion_str` | `strength` | +stacks |
   - Ignore unknown / non-allowlisted ids even if `family === STAT` (`aim`, `cloaked`, `decoy`, `mist`, `counter_reflect`, setup mult marks, …).
   - Sum multiple instances; `Math.max(1, base + delta)` per key (match buff helper floor).
   - Duration ownership stays on TurnClock `tickMarkDurations` — do not expire here.

2. **Live fold-in**
   - Combat-facing stats used for enemy/player actions must apply the helper when `marks` are available (extend `getEnemyFullStats` / `getPlayerFullStats` with optional `marks?: readonly Mark[]`, **or** a thin combat wrapper called from EnemyTurn/sim/resolve prep — document one path).
   - Buff path remains; Marks stack additively with buffs.

3. **No skill reauthor**
   - Do not change plant stacks/durations on leaf_whirlwind / flash_bomb / air_bullet.
