   - On successful `resolveSkill(analyze)` with Discover path:

     - Exclude source + current hand; reuse `discoverThree` + `predicate` (do not fork weight math).
   - `pendingDiscover.candidates` length ≤3; only ATTACK∩tag skills in fixture pool appear.

3. **Studied 2 on commit**
   - `commitDiscoverChoice` when pending source is `analyze` (or mark analyze commit helper):
     - Plant self mark **`studied`** duration **2**, metadata **chosen skill id** (stacks optional).
     - When that skill id later resolves as ATTACK with ≥1 hit, apply **penetration 0.2** (ignore 20% defense) via existing `applySkillPenetration` / damage path (fixture defense percent locked so AC is numeric).
     - Prefer: Studied applies for plays while mark duration remains; consume-on-attempt **or** duration-only — catalog “Studied 2” implies duration **2**, not single-shot only. **Prefer duration 2, no force consume on first hit** unless easier; lock one: **duration 2 wall-clock marks** already tick via reloj, bonus while present.
   - Non-analyze Discover commits do not plant Studied.

4. **Non-goals in resolve**
   - No STR % buff; no Mode; no Terrain.
