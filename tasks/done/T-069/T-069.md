## Context

Single Shuriken arms Aim. Barrage should be the **multi-hit tool SIDE** that chips 3×3 at M/L and, on any hit, plants a **+10% Setup** mark for the **next ATTACK** (attempt consume).

## Spec

### Must exist when done

1. **Authoring (`shuriken_barrage`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 2**, **CP 1**, **CD 2**, HP 0.
   - `baseDamage: 3`; `hitCount: 3` (3×3); M/L `allowedRanges`.
   - Tags TOOL/WEAPON/PHYSICAL/MULTI_HIT as available.
   - On ≥1 hit: plant self mark id e.g. **`barrage_setup`** (or `shuriken_barrage_setup`), duration **2** (or 1 attempt window — prefer 2 like Feint/Launched), `consume: ATTEMPT`, applies only when consuming skill is **ATTACK** (not SIDE), Setup mult **+10%** (`×1.1` via markDamageMultiplier or dedicated branch).
   - Remove “40% each” single-roll identity.
   - Honest description: 3×3 M/L; on hit next ATTACK +10% Setup.

2. **`resolveSkill` SIDE**
   - Multi-hit 3 independent rolls; costs paid.
   - If `hitsLanded >= 1`: plant setup mark on player; once-per-card (not per hit).
   - Full miss: no setup mark.

3. **Next ATTACK payoff**
   - When resolving ATTACK with mark among ATTEMPT spent: `damageDealt = floor(damage * 1.1)` (Setup bucket; stacks with other mark mults per existing order).
   - Consume at attempt (even full miss of that ATTACK).
   - SIDE plays do not consume this mark.
