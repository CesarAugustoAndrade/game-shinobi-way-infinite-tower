## Spec

### Must exist when done

1. **Authoring (`sweeping_kick`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 1**, **CP 0**, **CD 2**, HP 0.
   - `baseDamage: 7`; single hit; CLOSE; melee; TAIJUTSU/PHYSICAL/CONTROL tags as available.
   - Stun contract: **40%** chance, **Stun duration 1** on enemy when impact lands. Prefer either:
     - `effects: [{ type: STUN, duration: 1, chance: 0.4 }]` **and** resolve honors it for this skill; **or**
     - explicit field (e.g. `impactStun: { chance: 0.4, duration: 1 }`) wired in resolve — **lock one** in tests.
   - Honest description: 7 dmg CLOSE; 40% Stun 1 on hit.

2. **`resolveSkill` SIDE damage**
   - Pay costs; full hit under ports → `damageDealt === 7`.
   - Full miss → damage 0; **no** stun.

3. **Impact Stun 40%**
   - On **≥1 hit**, call injectible `rng` once (or ports.rng): if `rng() < 0.4`, append enemy STUN buff duration **1** (reuse `stunControlBuff` or equivalent Buff shape).
   - If `rng() >= 0.4`, no STUN buff.
   - Stun only on impact (not on miss). No self-stun on fail (unlike Mind Transfer).
   - No Mode; no band move; no setup mark required.
