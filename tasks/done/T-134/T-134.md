## Context

Outgoing Mark cuts already prove one-shot Mark helpers on the enemy-hit path. Reflect Marks should convert **stacks/100 → reflection percent** for the first qualifying incoming hit, deal reflected damage via existing mit, and **consume/strip** the reflect Mark (duration-1 identity).

## Spec

### Must exist when done

1. **Pure bridge helper**
   - e.g. `reflectPercentFromMarks(marks)` → `{ percent: number (0–1), marks: Mark[], consumed: boolean }` using first matching self-targeted `counter_reflect` or `rotation_reflect` (stacks/100; prefer higher stacks if both — or first-match order documented).

2. **Live EnemyTurn (or shared hit prep) honors bridge**

   - Reflected damage continues through existing `hit.reflectedDamage` handling.

   - Do not change Counter Stance / Rotation costs or plant shapes.
