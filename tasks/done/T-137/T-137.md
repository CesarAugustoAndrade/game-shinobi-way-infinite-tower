## Génesis

**Why this gap:** SOUL §9 Marks — DoT family: “Cada instancia suma daño · **Tick + decr. tras oportunidad del afectado** · BLEED físico; BURN elemental; POISON/TRUE según autoría.” Canon catalog [`#catalogo`](../../docs/combat-tactical-setup-spec.html#catalogo) rows that reauthored Bleed/Poison/Burn onto **`MarkFamily.DOT`** (e.g. kunai_slash Bleed 3×2) **removed** legacy `EffectType.BLEED` buffs. Live combat still ticks DoT only via **`processBuffTicks` on `activeBuffs`** (`EnemyTurnSystem`) — **no production reader** applies damage from `MarkFamily.DOT` marks. Planted Bleed/Poison/Burn Marks are decorative until duration ticks away via `tickMarkDurations` without ever dealing damage — §3.8 honesty failure.

**Code evidence:**
- Plants: `bleed` / `poison` / burn-style marks with `family: MarkFamily.DOT` + stacks (T-048 Kunai Slash, T-061 Poison Coat, T-078 Demon Slash, …); tests assert mark only, not buff.
- Live ticks: `processBuffTicks` handles buff BLEED/BURN/POISON (`EnemyTurnSystem.ts`); no `MarkFamily.DOT` damage path (grep outside tests empty).
- Clock: `tickMarkDurations` in TurnClock phase 04 decrements duration — does not deal DoT damage.
- Parallel: T-135 Shield Marks absorb; T-134 reflect Marks — DoT is the remaining MarkFamily live-fire gap for damage-over-time.

## Spec

### Must exist when done

1. **Pure DoT tick helper**
   - e.g. `tickDotMarksForActor(marks, target: CombatActor)` → `{ damage: number, marks: Mark[], logs?: string[] }`
   - Sum damage from marks where `family === MarkFamily.DOT` and `target` matches (stacks as flat damage v1 unless id-specific table already exists — prefer **stacks** as tick amount; document).
   - Do **not** decrement duration here if TurnClock already calls `tickMarkDurations` on phase 04 — avoid double-decr. Prefer damage-only on opportunity; duration stays on clock. If opportunity tick historically decrements buff DoT duration inside `processBuffTicks`, document Mark duration ownership: **clock owns duration**; opportunity owns damage.

2. **Live wire**
   - Enemy opportunity: tick DoT marks targeting **enemy** (player-applied bleeds).
   - Player opportunity / start-of-enemy-turn player phase: tick DoT marks targeting **player** if any (enemy-applied).
   - Apply damage to the correct HP pool; optional shield/mit: Marks DoT may skip shield or go through Mark shield helper (T-135) — prefer **through absorb helper if already present**, else direct HP with note.

3. **No skill reauthor**
   - Do not change bleed stack numbers on skills.
