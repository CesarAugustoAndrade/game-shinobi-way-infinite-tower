## Context

Kawarimi arms a self Substitution mark. The first enemy offensive that would deal `damage > 0` must nullify that hit, strip the mark, and retreat the player 1 band toward LONG without spending the manual move action.

## Spec

### Must exist when done

1. **Live wire on enemy offensive hit**
   - After outgoing Mark cuts (or at the documented incoming-damage prep), call `applySubstitutionIncoming(damage, marks, range)`.
   - If `consumed`: use returned `damage` (0), `marks`, and apply `range` / `retreatSteps` onto combat range state (forced PUSH — does **not** set `playerMoveUsedThisTurn`).
   - Persist marks on the enemy-action result like other Mark updates.

2. **Consume rules (honor helper)**
   - `damage <= 0` does not consume (helper already).
   - Only first armed Substitution; second hit after strip takes normal damage.

3. **No skill reauthor**
   - Do not change Kawarimi costs/plant duration.
