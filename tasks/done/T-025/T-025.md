## Context

Sharingan 3 Mode and Chidori skill exist. Pure resolve still treats Chidori as a plain melee ATTACK with no Mode consume and no MEDIUM grant. This task authors the Mode interaction and wires pure playability/resolve so that when Sharingan 3 is ON and 2 charges can be spent at attempt, Chidori is legal at MEDIUM and spends **2** charges; otherwise base (CLOSE/melee) ranges and no free Mode spend.

## Spec

### Must exist when done

1. **Authoring (`chidori`)**
   - `cardRole: CardRole.ATTACK` (or SIDE_ATTACK only if SOUL forced Side — it is Attack payoff → **ATTACK**).
   - `modeInteraction: { modeId: 'sharingan_3', consumeCharges: 2 }` (or equivalent explicit fields).
   - Description states honestly: with Sharingan 3-Tomoe ON, costs **2 charges** at attempt and may be used at **MEDIUM**; without Mode, no charge route / no MEDIUM grant.
   - Do **not** invent baseDamage retune or secret % beyond existing piercing/pen fields.

2. **Range when Mode ON**
   - Playability / resolve validation: if `sharingan_3` is **ON** on the Mode board, Chidori is in-range at **MEDIUM** (and CLOSE if already legal). Prefer expanding effective allowed ranges for this skill when Mode ON rather than permanently authoring MEDIUM on the static skill row (static MEDIUM would violate “gana MEDIUM” only under 3T).
   - If Mode **OFF** or insufficient charges for the 2-spend: **no** MEDIUM grant (CLOSE-only / melee default as today).

3. **Charge spend at attempt**
   - When resolving Chidori with Sharingan 3 ON and `charges >= 2`: spend **2** at attempt (auto; no manual `intent.modeCharges` required), even if hits later miss.
   - If Mode OFF or charges `< 2`: do not grant MEDIUM; if player somehow forces resolve at CLOSE only without Mode path, do not spend charges; reject or resolve as base ATTACK without Mode consume (document: reject when at MEDIUM without Mode/charges; allow CLOSE base without spend).
   - Prefer same auto-spend helper style as T-018/T-020 if present.
