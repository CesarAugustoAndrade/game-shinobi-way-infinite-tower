## Context

Uzumaki clone payoffs and Wire Reel exist. Shunshin should be the cheap SUPPORT that repositions **one band** (player-chosen approach or retreat) without burning the once-per-turn manual move, and arms the **next SIDE/ATTACK** with a legible **+1 DEX** attempt mark — still a legacy SPEED % buff with no role.

## Spec

### Must exist when done

1. **Authoring (`shunshin`)**
   - `cardRole: CardRole.SUPPORT`.
   - Costs: **AP 1**, **CP 4**, **CD 3**, HP 0 (catalog).
   - `baseDamage: 0`; no hitCount.
   - Ranges: ANY / full bands (catalog ANY).
   - Movement contract: one band step for the **user**, kind chosen at play:
     - Prefer `bandMove` default **SELF_APPROACH** plus resolve honor of `intent.movement` / `intent.bandChoice` for **SELF_APPROACH** or **SELF_RETREAT** (one step). Document the intent field name in tests.
   - Next-offensive contract: self mark id **`shunshin_dex`** (or `body_flicker_dex`), duration **1**, `consume: ATTEMPT`, stacks/metadata encoding **+1 DEX** (honest integer; not a % SPEED buff).
   - Remove primary identity of SPEED +0.40×2 effect.
   - Honest description: move one chosen band (no manual move spend); next Offensive +1 DEX.

2. **`resolveSkill` SUPPORT**
   - Pay costs; `damageDealt === 0`.
   - Apply band step from authored/intent kind; **`playerMoveUsedThisTurn` unchanged** (card movement, SOUL §10).
   - From LONG + retreat (or CLOSE + approach): no band change (edge) still **ok** play; mark still plants.
   - Plant **`shunshin_dex`** on self (owner/target player) duration 1, ATTEMPT consume.
   - No Mode board mutation; no Terrain/Heat.

3. **Next Offensive +1 DEX**
   - On a later SIDE or ATTACK resolve that spends own ATTEMPT marks: if `shunshin_dex` is among spent, apply **+1 DEX** to that skill’s damage resolution in pure path:
     - Preferred: if `scalingStat === DEXTERITY`, add **`scalingPerPoint * 1`** to damage before/with hit aggregation; if non-DEX scaling, still consume mark and apply **+1** flat damage **or** document equivalent pure DEX contribution — **lock one** in AC3.
   - Mark **consumed at attempt** (even on full miss), matching SOUL own-mark attempt rule.
   - SUPPORT / MODE plays do not consume `shunshin_dex` unless they are classified Offensive (ATTACK+SIDE only).
