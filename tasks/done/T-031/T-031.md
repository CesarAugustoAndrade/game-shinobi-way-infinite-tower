     - `consumeAllCharges: true`

Family `STAT` preferred. **Not** IMPACT-gated (applies on successful commit even if all hits miss — finisher self-cost).
   - Honest description: requires Gate of Limit ON; 5 hits; +15%/remaining charge; consume all + close Gate; self-Vulnerable 30% for 2 durations.
   - Drop legacy “self-stun / TRUE nuke” as identity; damageType may stay PHYSICAL or TRUE only if catalog-compatible — **prefer physical multi-hit like Peacock** unless catalog forces TRUE (catalog lists dmg only; do not invent TRUE pierce rules).

2. **`resolveSkill` behavior**
   - Reuse Peacock Limit path: no Limit ON / 0 charges → reject `mode-required`, consume nothing.
   - On ok: mult `1 + 0.15 * C` on total multi-hit damage (same floor convention as T-021 tests); spend all charges at attempt; Mode → COOLDOWN.
   - After offensive resolve: self `vulnerable` Mark present on player target with duration 2.
   - `hitCount` stays **5**. Gate of Life ON alone (without Limit) **must reject** (Limit-only, unlike T-030).

3. **Vulnerable honesty (minimal)**
   - Mark must be queryable on `state.marks` with `target === PLAYER` (or `CombatActor.PLAYER`).
   - If an existing enemy-damage path can read self `vulnerable` for +30% taken, wire it; if not, **AC only requires mark plant** this task (do not invent a second damage pipeline). Document OOS if enemy mult not wired.
