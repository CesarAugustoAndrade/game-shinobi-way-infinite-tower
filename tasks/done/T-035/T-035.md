## Spec

### Must exist when done

1. **Authoring (`64_palms`)**
   - `cardRole: CardRole.ATTACK`.
   - `hitCount: 8`; `baseDamage: 3` (catalog 8×3).
   - Costs: **AP 4**, **CP 7**, **CD 5**, HP 0.
   - `allowedRanges: [CombatRange.CLOSE]`.
   - `penetration: 0.3` (30% defense ignored — same honesty as Twin Lion).
   - Mode/Mark contract (prefer data-driven `modeInteraction` extensions over skill-id hardcode):
     - `modeId: 'byakugan'`, `family: HYUGA` / `MODE_FAMILY.HYUGA`.
     - Enhance only when Mode ON **and** enemy `chakra_point` **stacks ≥ 2** (STAT merge total stacks; T-026).
     - When enhance applies: `consumeCharges: 1` at **attempt** (before hits).
     - Damage mult from marks: **+0.10 per CP stack**, **cap 0.40** (4+ stacks → +40% only). Prefer fields e.g. `requireMarkId: 'chakra_point'`, `minMarkStacks: 2`, `damagePerMarkStackBonus: 0.1`, `damageMarkStackCap: 0.4` (names flexible if documented in tests).
     - **No** flat `damageMultBonus: 0.5` (that is Twin Lion only).
   - Do **not** requireOn alone without CP (base 8-hit plays without setup — catalog enhance clause is conditional).
   - Honest description: 8×3; with Byakugan + ≥2 CP: +10%/stack cap 40%, spend 1 charge, pen 30%, consume CP on impact; miss keeps marks.
   - Drop legacy TRUE/drain/stat-% debuffs as primary identity (anti-visión secret %).

2. **`resolveSkill` behavior**
   - **Base path:** Byakugan OFF or CP stacks `< 2`: no charge spend; no mark-stack mult; multi-hit 8 resolves; CP marks **not** removed solely by this skill unless hits land and marks are IMPACT-consumable (if CP already IMPACT-tagged, consume only on ≥1 hit — same as Twin Lion miss-keep).
   - **Enhanced path:** Byakugan ON + CP stacks `S ≥ 2`: spend **1** charge at attempt; `modeDamageBonus = min(0.4, 0.1 * S)`; on ≥1 hit apply mult to total damage; IMPACT-consume enemy CP marks; on **full miss** keep CP marks and still spent charge (attempt cost) — lock miss/charge in tests: **charge spends at attempt even if all miss** (SOUL charges at attempt); marks keep on miss.
   - Penetration 0.3 applied via existing skill penetration path when present.
   - Twin Lion behavior unchanged.

3. **Compose**
   - Count stacks via existing Mark STAT merge (`chakra_point.stacks`), not separate instance count only.
   - Prefer shared helpers for “enemy mark stacks by id.”
