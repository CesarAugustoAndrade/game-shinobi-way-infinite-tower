## Context

Draw weights and Discover sampling exist; resolve plays SUPPORT without freeing a hand slot or generating Discover offers. This task **wires Discover into the pure resolve/hand model**: after a legal Discover Support commit, produce ≤3 candidates via existing `discoverThree`, expose them for selection, and commit the chosen skill into the hand (disabled if on CD). No secret redraw of a dead hand; no inventing new Discover rules.

## Spec

### Must exist when done

1. **Resolve path for Discover Supports**
   - When `resolveSkill` succeeds on a skill with authored `cardRole: SUPPORT` and `skill.discover` (count defaults to 3 if omitted but present):
     - Support side-effects already in scope (marks etc.) still run.
     - Result includes a **Discover offer**: up to `min(3, eligible)` distinct candidates from playable pool, current weights, **excluding** source skill id and skills currently in the provided hand.
     - Source skill is **removed from hand** (slot freed) on successful resolve — hand is part of `ResolveSkillState` or a parallel hand bag passed through resolve (extend state minimally if hand is absent today).

2. **Candidate rules (call T-003 `discoverThree` — do not fork formula)**
   - Filter from `DiscoverSpec` (`tag`, `element`) maps to `DiscoverFilter`.
   - Cooldown skills may appear; `HandSnapshot.disabled` / reasons include cooldown when not ready.
   - Offer generation uses injected `rng` via ports (same as T-003 testability).

3. **Commit choice (pure)**
   - `commitDiscoverChoice(state, chosenSkillId)` (name flexible): inserts the chosen candidate into hand (occupies freed slot); non-chosen do **not** remain as extra hand cards (virtual pool).
   - Choosing a CD candidate yields a **disabled** hand entry (playability snapshot).
   - Invalid choice id → no hand mutation (consume nothing beyond the already-resolved Support — choice reject does not refund Support; document; AC only on valid path + invalid no-extra-insert).

4. **Non-Discover Supports**
   - SUPPORT without `discover` remains marks-only (or existing behavior); no spurious Discover offer.
