## Context

Hand size 4 and posture already exist. The draw pile model contradicts SOUL: each turn must sample **4 distinct** cards from the **entire playable loadout (6–20, no PASSIVE)** with transparent weights, then **virtually discard** the hand (next turn = full pool again). CD/AP/range do not exclude from the lottery — cards may sit **disabled** in hand.

## Spec

### Must exist when done

1. **Playable pool (pure):**  
   From loadout skills → unique hand-role techniques, exclude PASSIVE, size conceptually 6–20 (enforce max if existing cap helpers remain; min-6 may stay loadout-config concern). No deck residual.

2. **`effectiveWeight` (pure, SOUL v1):**  
   ```
   effectiveWeight = max(1, baseWeight + postureBonus + modeBonus + supportBonus − activeSelf − cooldownPenalty)
   ```
   with defaults: `baseWeight = 2` (or skill.baseWeight); Main Attack **+0** inherent (no free Main weight);  
   posture by **cardRole**: Aggressive ATTACK +1; Balanced MODE +1 and SIDE_ATTACK +1; Defensive SUPPORT +1;  
   `activeSelf` −1 when that Mode skill is ON; `cooldownPenalty` −1 when not ready;  
   optional mode/support weight modifiers from combat state (0 if Modes not live); **no weight cap**.  
   **Forbidden:** inferring role/category from expected damage for weight.

3. **`drawHand(pool, combatState, size = 4, rng)` (pure):**  
   Weighted sample **without replacement** over the **full pool** every call; inject `rng` (no hidden `Math.random` as sole path — keep testability).  
   Each hand entry is a **snapshot** including playability (e.g. disabled if on CD / unaffordable / wrong range) — CD still eligible for draw.  
   First hand of combat: **same rules** (no opening tutor).

4. **Virtual discard:**  
   End-of-turn / new-turn API clears hand and draws again from full pool; **delete** `reshuffle`, persistent `deck`, and `discard` as the combat model. Update `CombatState` (and callers) so deck/discard are gone or non-normative empty husks removed in this task (prefer full delete).

5. **Dead hand:**  
   If all 4 snapshots are unplayable, **do not** redraw or inject free attacks; only document that move / posture / Pass remain (existing board actions — do not reimplement board here).

6. **Discover 3 (pure):**  
   After resolving a Discover support (caller supplies filter + current hand + pool): up to **3** distinct candidates from pool matching filter, current weights, exclude source + current hand; CD candidates allowed (enter disabled if chosen); pick one via rng to fill the freed hand slot; non-chosen return to virtual pool. Gate AC for Discover+CD.
