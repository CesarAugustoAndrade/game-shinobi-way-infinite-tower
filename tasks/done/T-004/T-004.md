## Spec

### Must exist when done

1. **Tactical Setup state (pure):**  
   A collection of Marks on combat (or actor) state: each Mark has at least SOUL fields — `id`, `sourceSkillId`, `owner`, `target`, `duration`, `stacks`, `trigger?`, `consume?` (attempt | impact | none/read).  
   Helpers: `addMark` (stacking per family rules below), `listMarks(owner|target filter)`, immutable updates.

2. **Stacking / families (v1 pure rules, SOUL §9 table — implement as data-driven flags, not freeform design):**  
   - **DoT-like marks:** instances can coexist / stack damage contribution as authored.  
   - **Shield-like:** additive absorption instances.  
   - **Stat buff/debuff marks:** additive integers (never secret % translation in this layer).  
   - **Hard control:** coexisting instances; resolution of “two Stun 1 → one skip” may be a pure helper stub documented for turn systems.  
   - Marks **do not** mutate Room `TerrainDefinition`.

3. **Consumption API (pure):**  
   - `consumeOnAttempt(setup, actor, skillIntent)` — removes/spends **own** marks tagged attempt-consume when a valid action is committed, **even if the action later misses/fails**.  
   - `consumeOnImpact(setup, target, hitResult)` — spends **enemy** consumable marks only if **≥1 hit landed**.  
   - Read-only marks (no consume) remain unless duration expires or explicit rule.

4. **Duration tick (pure):**  
   Decrement player-owned support/mark durations in a helper suitable for clock phase 04 (after draw). At 0, mark no longer affects actions. Encounter reset (T-002) must be able to clear all Marks — export `clearMarks` / integrate with frontier reset if that helper exists.

5. **Multi-hit resolution rules (pure, SOUL §9):**  
   Given `hitCount` N (default 1):  
   - N independent hit/crit/mitigation rolls (fixture rng).  
   - Default: `effects[]` / once-per-card procs / setup consumes / mode charges (charge hook optional stub) fire **once per card** if **≥1 hit**, unless `perHit: true`.  
   - **DRAIN/heal-from-damage:** once on total post-mitigation damage if applicable (helper contract).  
   - AC must cover **partial multi-hit**: 1 of N hits land → once-per-card consume yes; 0 hits → no impact-consume of enemy marks; attempt-marks already consumed at commit.
