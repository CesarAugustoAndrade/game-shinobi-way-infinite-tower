## Context

CTS Tripwire (and any future Mark stun) leaves HARD_CONTROL on the board. Enemy/player/sim action start must honor **at most one skip** from stun-type HARD_CONTROL Marks targeting that actor, without double-skipping stacked Stun-1 instances, and without Bound contributing.

## Spec

### Must exist when done

1. **Refine pure skip helper**
   - `resolveHardControlSkips(setup, target?: CombatActor)` (or documented filter): count only **stun-type** HARD_CONTROL marks (e.g. `id === 'stun'` or explicit allowlist), optionally filtered by `target`.
   - **Exclude** `bound` (and any non-skip HARD_CONTROL ids).
   - Return `Math.min(1, totalStacks)` — two Stun-1 instances → **1** skip (SOUL §9).
   - Optional companion: `actorHasHardControlSkip(marks, actor)` boolean for call sites.

2. **Live wire (enemy required; player/sim if cheap)**
   - `executeEnemyAction`: if skip helper says enemy is hard-controlled → same early return as buff stun (log + no attack); prefer **OR** with existing buff stun so dual-path content still works.
   - Prefer also: sim enemy/player stun gates and player playability stun gate read the same helper (SOUL §15 parity) when the call site already has `marks`.
   - Do **not** strip Bound; do **not** end Modes (Stun does not end Modes — SOUL §8 / anti-visión).

3. **Duration ownership**
   - Do not invent a second duration tick; TurnClock / existing mark duration owns expiry. Skip is opportunity-gated only.

4. **No skill reauthor**
   - Do not change Tripwire chances, Bound plant, or migrate buff stuns to Marks in this task.
