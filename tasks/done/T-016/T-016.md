## Context

Draw already multiplies by optional `supportBonuses`. SOUL Support techniques schedule **one-shot** next-draw weight deltas. Missing is a pure **pending bag**: enqueue on Support resolve, materialize into `supportBonuses` for exactly one snapshot/draw, then clear. This multiplies T-003 without dual weight physics.

## Spec

### Must exist when done

1. **Pending support-weight bag (pure model)**
   - Structure e.g. `PendingSupportWeight[]` with `{ skillId: string; delta: number }` (or map) representing bonuses for the **next** hand draw only.
   - `enqueueSupportWeightBonuses(bag, entries) → bag`
   - `consumeSupportWeightBonuses(bag) → { bonuses: Readonly<Record<string, number>>; bag: empty }` — sums by skillId for the draw context, leaves bag empty after consume (one-shot).

2. **SOUL enqueue rules (from named Supports)**
   - **Chakra Control Drill** (`chakra_control_drill`): on successful play/resolve of that SUPPORT, enqueue `{ skillId: mainAttackId, delta: 2 }` when `mainAttackId` is a non-empty string; if Main null/empty, enqueue nothing for Main (do not invent a Main).
   - **Gate Prep** (`gate_prep`): on successful play/resolve, enqueue `delta: 3` for each Gate Mode skill id present in SOUL Mode table / catalog: at least `gate_of_life` and `gate_of_limit` (stable ids matching `MODE_DEFINITIONS` / skills). Do not invent extra Gate skill ids.

3. **Draw integration**
   - Pure path: before `drawHand`/`drawNewTurnHand`, caller may `consumeSupportWeightBonuses` and pass result as `supportBonuses` in `WeightContext`.
   - Document that live turn-start (T-012) should consume once per snapshot/draw phase; unit tests drive pure consume+weight without requiring T-012 merged.

4. **Resolve/SUPPORT hook (pure)**
   - Either extend `resolveSkill` SUPPORT success to accept optional `{ mainAttackId, pendingSupportWeights }` and return updated bag, **or** export pure `applySupportWeightOnPlay(skill, ctx) → entries` called by resolve tests. Invalid/non-matching skills produce no entries.
   - Playing Drill does **not** permanently change skill `baseWeight`.
