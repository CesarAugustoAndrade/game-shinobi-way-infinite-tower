## Spec

### Must exist when done

1. **Authoring (`primary_lotus`)**
   - `cardRole: CardRole.ATTACK`.
   - `hitCount: 3`; `baseDamage: 7` (catalog 3×7); keep CLOSE via `allowedRanges: [CombatRange.CLOSE]` or MELEE default.
   - Costs aligned to catalog/SOUL packaging: **AP 5**, **HP 15**, **CD 5** (replace legacy AP 2 / CD 4 if still present). Chakra 0.
   - `modeInteraction` declares GATES finisher:
     - `family: MODE_FAMILY.GATES` (or `'GATES'` consistent with Peacock).
     - `requireOn: true` with **family scope** (not a single Life-only modeId that breaks Limit boards).
     - `consumeAllCharges: true`.
     - `damagePerChargeBonus: 0.15`.
     - Optional: omit fixed `modeId` **or** document that resolve **binds** the live ON GATES instance at commit; do not hard-require only `gate_of_life`.
   - Honest description: requires a Gate Mode ON; 3 hits; +15% per remaining charge; consumes all charges and closes the Gate at attempt.
   - Remove legacy STR % buff as primary identity (anti-visión: Mode/finisher is not a decorative stat toggle). Do not invent new self-stun for Primary (that is Hidden Lotus).

2. **`resolveSkill` — family-scoped GATES finisher**
   - When skill requires a Mode ON by **family** (Primary Lotus): if **no** ON instance with that `family` → reject `mode-required` (or existing equivalent), **consume nothing**.
   - When ON: bind that instance’s `modeId` for charge read/spend (only one GATES can be ON).
   - On successful commit path: damage mult uses **remaining charges before spend** as `C` → mult `1 + 0.15 * C` (same additive stack path as Peacock `damagePerChargeBonus`).
   - Spend **all** remaining charges at **attempt** (`consumeAllCharges`); Mode ends → COOLDOWN via existing `trySpendCharges` zero path.
   - `hitCount` stays **3**. Invalid Mode → no AP/HP/CD/charges mutation.

3. **Compose with Peacock path**
   - Prefer shared helpers for “resolve target Mode id from modeId | family” and per-charge mult; do not fork a second finisher pipeline.
   - Fixed-`modeId` skills (Peacock, Chidori, Rasengan) must keep current behavior.
