## Spec

### Must exist when done

1. **Posture damage/defense (SOUL v1):**  
   Aggressive deal/take **×1.20**; Balanced **×1**; Defensive deal/take **×0.80**. Update pure `postureDamageMod` / `postureDefenseMod` (and any duplicated constants) to these values. Manual posture switch remains **1 AP** (existing `POSTURE_SWITCH_AP_COST` / switch helpers — assert, do not invent).

2. **Mode vs Attack range (pure):**  
   - **Attack / Side / Support (non-Mode play):** always require current band ∈ `allowedRanges` (existing `skillAllowedAt`).  
   - **Mode activation:** range checked **only on activate**; once Mode is ON, band changes do **not** force Mode off for range.  
   Helper e.g. `canActivateModeAt(def, range)` vs `canPlayNonModeSkillAt(skill, range)`; playability context may take `modeActivation?: boolean` / `isModeOn?: boolean`.

3. **Movement → reactions (pure):**  
   After voluntary or forced move: if `moved === true`, collect ordered reactions (from registry and/or Mark reaction family when T-004 types exist; empty registry OK if API is real).  
   If `moved === false` (boundary: PUSH at LONG, PULL at CLOSE): **no** reactions.  
   Forced/card movement **does not** set `playerMoveUsedThisTurn`. Voluntary move still 1 AP, once/turn.

4. **Hand snapshot playability:**  
   Pure “one prioritized block reason” for a skill in context (extend/stabilize `getSkillBlockReason` order). Cards with AP cost > current AP are **disabled** and still occupy a hand slot (no auto-drop). Dead hand: no redraw here (T-003).

5. **FREE_FIRST_SKILL (hard SOUL):**  
   Pure/live path: waives **only** the first skill’s **chakra** cost. Must **not** zero AP cost, HP cost, Mode upkeep, charges, or cooldown. Tests prove AP/HP still charged when flag set. Align passive log text to “first chakra free” (not “all resources”).

6. **v1 closed:** card resolution helpers introduced here must **not** read Room Terrain/Heat to change card legality or damage (distance gates only; existing terrain pipelines outside card authoring may remain but no new card↔terrain hooks).
