## Context

Mode machine and resolve commit exist. Rasengan does not declare or apply the clones payoff. This task **authors** Rasengan’s Mode interaction and **wires pure resolve** so that when Shadow Clones is ON, Rasengan pays **1 charge at attempt** and deals **+50%** damage relative to base resolution (same hit rolls), without requiring the caller to set `enhanced`/`modeCharges` by hand.

## Spec

### Must exist when done

1. **Rasengan authoring**
   - `rasengan` skill: `cardRole: ATTACK` (or SIDE_ATTACK only if SOUL forced — SOUL lists it as Attack payoff → **ATTACK**).
   - `modeInteraction`: `{ modeId: 'shadow_clone', family: CLONES/MODE_FAMILY.CLONES, consumeCharges: 1 }` plus a declared enhance of **+50%** when that Mode is ON — prefer extending `ModeInteraction` with an optional field e.g. `damageMultBonus?: number` (**0.5**) **or** a documented skill-level field used only when Mode ON. Do not invent other bonuses.
   - Description states base viable; with clones ON +50% and 1 charge at attempt (honest text).

2. **resolveSkill auto Mode payoff (pure)**
   - For ATTACK/SIDE with `modeInteraction.modeId`:
     - If that Mode is **ON** on the board and `consumeCharges` > 0: call spend-charges at **attempt** (same phase as existing `intent.modeCharges` path). Prefer skill authoring when `intent.modeCharges` omitted; if intent supplies charges, do not double-spend.
     - If Mode ON and damage mult bonus authored (0.5 for Rasengan): apply **+50%** to damage dealt for that resolve (consistent with SOUL; use `floor` of total post-hit sum or per-hit base — pick one, lock in AC). If Mode **OFF** or missing: base damage only, **no** charge spend.
   - If Mode ON but **insufficient charges** for consume: SOUL “gasto al intento” — spend fails → **no** enhance and **no** partial free enhance (reject enhance; either still resolve base without enhance **or** invalid — prefer: resolve **base** damage, charges unchanged when spend fails; document in test).
   - Miss path: charge still spent at **attempt** if Mode ON and consume declared (SOUL attempt timing), matching existing attempt-mark semantics.

3. **Does not break** non-Mode skills or SUPPORT/MODE roles; Barrage may keep explicit intent path or gain same auto-consume if already authored (optional; AC only requires Rasengan).
