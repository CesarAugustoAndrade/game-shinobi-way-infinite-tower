## Spec

### Must exist when done

1. **requireOn hard gate**
   - When skill has `modeInteraction.requireOn` and `modeId`: if that Mode is **not ON** on the player Mode board → `resolveSkill` **rejects** with a stable reason (e.g. extend reject union or reuse an existing block reason), **consume nothing** (AP/CP/HP/CD/charges/marks unchanged) — same as other invalid intents.

2. **Per-charge damage scale (Peacock / authored mult)**
   - When Mode ON: read **remaining charges before spend** as `C`.
   - Damage mult = `1 + 0.15 * C` for Peacock (SOUL +15% per charge). Prefer authoring `modeInteraction.damagePerChargeBonus: 0.15` (or equivalent) so the number is data-driven; default only for Peacock AC.
   - Apply mult to total multi-hit damage (or each hit’s base consistently — lock one approach in tests). `hitCount` stays **6**.

3. **Consume all charges and close Gate**
   - On successful validate+commit path for Peacock: spend **all remaining charges** on `gate_of_limit` at **attempt** (not a fixed 4 if fewer remain — authoring `consumeCharges: 4` means cap/all; SOUL “todas”). After spend to 0, Mode ends → COOLDOWN per T-005 (`trySpendCharges` zero path).
   - Prefer: `trySpendCharges(board, modeId, currentCharges, turn)` so any C∈1..max closes the Mode.
   - If requireOn passed but charges somehow 0: treat as not ON / reject (no free Peacock).

4. **Authoring honesty**
   - Keep description; optional field for 0.15 per charge; fix `consumeCharges` semantics to “all remaining” in notes/fields if fixed-4 would underspend when C<4 or over-require when C>4 — SOUL wins: **all remaining**.
