## Génesis

**Why this gap:** SOUL §7 Reloj — cooldown semantic: used on turn T with CD N → blocked T+1…T+N, ready T+N+1 (`readyOnTurn = T+N+1`). Canon [`#reloj`](../../docs/combat-tactical-setup-spec.html#reloj) / [`#aceptacion`](../../docs/combat-tactical-setup-spec.html#aceptacion) (“Cooldown 2 → bloqueada en 2 manos siguientes”). §15 Cooldown reset: reinicia cartas (and Modes off) without activating Modes / refilling charges. `resolveSkill` already gates with `isSkillReadyOnTurn` (`ResolveSkillSystem.ts` ~841), but **`getSkillBlockReason` still uses `skill.currentCooldown > 0` only** (`skillPlayability.ts` ~89) — UI/hand greying and shared playability can disagree with normative CD. T-002 Close explicitly noted: replace live `currentCooldown` gates with `isSkillReadyOnTurn`. Separately, `processPassivesOnKill` COOLDOWN_RESET clears **`currentCooldown: 0` only** — leaves `readyOnTurn` armed, so SOUL reset is incomplete if readiness is markSkillUsed-driven. Deferred in T-141–T-144 discards; now the best non-Mark residual.
