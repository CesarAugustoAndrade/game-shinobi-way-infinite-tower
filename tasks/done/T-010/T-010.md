## Spec

### Must exist when done

1. **Card face (hand):**  
   - Badge from `cardRole`: **SUPPORT | MODE | SIDE | ATTACK** (SIDE_ATTACK displays as SIDE).  
   - **Main Attack** ribbon when skill id === configured `mainAttackId`.  
   - Show AP, CP/HP, remaining CD, range, hit count when authored.  
   - **Red text** (or dedicated class) when playing would consume Mode charges / end Mode.  
   - Disabled cards: **one** prioritized block reason visible (tooltip/title/aria already partial — ensure single reason).  
   - Remove/replace TOGGLE/ACTIVE role badge as the primary category label (PASSIVE may remain for non-hand display only).

2. **Contextual preview (hover/focus/select):**  
   Pure view-model preferred (`combatSkillViewModel` or sibling): base damage estimate vs enhanced with **named sources** (posture, Mode, Mark, etc. — zeros when systems absent). Do not show false enhanced promises when no Mode/Mark applies.

3. **Combat Modes panel:**  
   Lists active Modes: name/stage, charges/max, upkeep cost, upkeep priority order — **not** buried only as a generic buff chip.

4. **Tactical Setup panel:**  
   Own + enemy Marks: icon/name, stacks, duration clock, trigger, consume rule summary.

5. **Skill Config (exploration / out of combat):**  
   Surface Main Attack selection (read-only in combat), mode upkeep priority order, and **weight breakdown** behind one click/inspector — not on every hand card face.

- [x] R2 projects state; no formula ownership (call R0 helpers/view-models)
- [x] No inventing UI metrics absent from SOUL
- [x] Accessibility: badges/panels have text/aria, not color-only
