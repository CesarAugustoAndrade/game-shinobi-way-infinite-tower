## Spec

### Must exist when done

1. **Enhanced condition (all required)**
   - Byakugan Mode **ON** on player board (`modeInteraction.modeId`), **and**
   - At least one enemy-targeted Mark with id `chakra_point` (or project-stable CP id) present on `state.marks` before hit resolution.
   - If either missing: resolve as **base** 2× hits (no +50%); do **not** invent enhance. (Soft base play allowed — unlike Peacock hard requireOn for Gate Limit — SOUL says “with Byakugan+CP → enhance”; base without setup remains viable. If current authoring `requireOn: true` means hard reject without Byakugan, pick **SOUL base-viable**: allow play without Byakugan at base damage; document. Prefer SOUL: base viable without setup; enhance only with both.)

2. **On enhance (Byakugan ON + CP present)**
   - Damage total (or per-hit consistently) × **1.5** (+50%).
   - Penetration **30%** applied in the pure damage path used by resolve (if resolve currently ignores `skill.penetration`, wire it for this enhance case at minimum).
   - On **≥1 hit**: consume enemy `chakra_point` IMPACT marks via existing `consumeOnImpact` (ensure CP marks are IMPACT-consumable on the board fixture).
   - On **0 hits (full miss)**: CP marks **remain** (SOUL fallo conserva).

3. **Authoring cleanup**
   - Twin Lion must not permanently self-`markEffects` apply a free CP every cast if that contradicts “read existing CP.” Prefer remove apply-on-cast CP from Twin Lion; Air Palm/other Supports apply CP. Description stays SOUL-true.
   - Keep `hitCount: 2`, costs as authored.

4. **Charge spend**
   - SOUL Twin Lion text in §12 does not require Byakugan charge spend (Rotation spends 1 charge). Do **not** invent charge spend for Lions unless HTML row requires it — default **no** Byakugan charge consume for this task.
