## Spec

### Must exist when done

1. **Authoring (`rising_wind`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 1**, **CP 0**, **CD 2**, HP 0.
   - `baseDamage: 8`; single hit; CLOSE; melee; TAIJUTSU/PHYSICAL/SETUP tags as available.
   - `markEffects`: own/player mark id **`launched`**, duration **2**, `consume: ATTEMPT` (or equivalent own attempt consume), metadata for **+20%** setup mult on next **MELEE ATTACK** (stacks unused or constant `LAUNCHED_SETUP_MULT = 1.2`).
   - Remove primary STR +0.25 duration-1 buff identity.
   - Honest description: 8 dmg CLOSE; Launched 2 → next MELEE ATTACK +20% setup.

2. **`resolveSkill` SIDE**
   - Pay costs; full hit → `damageDealt === 8` under test ports.
   - On **≥1 hit** (or always on ok resolve if hit is guaranteed under ports): plant `launched` duration 2 on player (own setup).
   - On **full miss**: no plant; damage 0.
   - No Mode; no band move; no Feint interaction required.

3. **Next MELEE ATTACK +20%**
   - When resolving `cardRole === ATTACK` with `attackMethod === MELEE` (or catalog melee CLOSE ATTACK), if `launched` is among own ATTEMPT marks spent this attempt: apply **×1.20** setup mult to damage (same layer as Off-Balance bucket if already present — additive composition must be documented; prefer multiply once with other setup mults already in the pipeline).
   - **Ranged ATTACK** does **not** gain the +20% from Launched (and still consumes at attempt if policy is “any ATTACK consumes own attempt marks” — prefer: only MELEE ATTACK spends `launched`; SIDE never spends it for payoff).
   - On full miss MELEE ATTACK: consume at attempt per SOUL own-mark rule; no damage bonus applied.
   - Without `launched`, baseline damage unchanged.
