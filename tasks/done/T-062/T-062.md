## Spec

### Must exist when done

1. **Authoring (`cloak_invis`)**
   - `cardRole: CardRole.SUPPORT`.
   - Costs: **AP 1**, **CP 3**, **CD 4**, HP 0.
   - `baseDamage: 0`; ANY range; tags STEALTH/NINJUTSU/MARK as available.
   - `markEffects`: self mark id **`cloaked`** (or `cloak`), duration **2**, `consume: ATTEMPT`, applies only when the consuming skill is **`cardRole === ATTACK`** (not SIDE).
   - Contract of mark: force critical on that ATTACK’s hit rolls + **+1 DEX** damage contribution (mirror T-043: if `scalingStat === DEXTERITY` add `scalingPerPoint`, else +1 flat).
   - Remove primary SPEED +0.6 / DEX +0.5 % buff identity.
   - Honest description: Cloaked 2; next ATTACK force crit +1 DEX; consume on attempt.

2. **`resolveSkill` SUPPORT**
   - Pay costs; `damageDealt === 0`.
   - Plant `cloaked` duration 2 on player.
   - No enemy marks; no Mode board mutation; no Terrain/Heat.

3. **Next ATTACK attempt package**
   - When resolving `cardRole === ATTACK` with player `cloaked` present:
     - **Consume** `cloaked` at **attempt** (even if all hits miss).
     - Hit rolls for that resolve use **`forceCrit: true`** (or equivalent so every independent hit is a critical).
     - Apply **+1 DEX** contribution as above (on damage aggregation; if full miss, damage stays 0 but mark is still gone).
   - SIDE / SUPPORT / MODE plays **do not** consume `cloaked` for this package.
   - Without `cloaked`, baseline ATTACK crit rules unchanged.
