Explosive Tag is a single PUSH chip. Barrage should be the **multi-hit fire tool SIDE**: **3×5** at M/L, and on any hit plant **Exposed 2** so the next **ranged ATTACK** gains **+15%** Setup (existing T-023 mult) and consumes at attempt.

## Spec

### Must exist when done

1. **Authoring (`explosive_barrage`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 2**, **CP 3**, **CD 4**, HP 0.
   - `baseDamage: 5`; `hitCount: 3` (3×5); M/L `allowedRanges`.
   - Tags: TOOL / FIRE / MULTI_HIT (and WEAPON if used elsewhere) as available.
   - Element FIRE; RANGED attack method.
   - On ≥1 hit: plant self or enemy-facing Setup mark id **`exposed`**, duration **2**, `consume: ATTEMPT` (match T-023 / Blastback shape so next ranged ATTACK pays ×1.15). Prefer **self** attempt-mark ownership consistent with Blastback/Off-Balance (player holds the Setup arming the next ATTACK).
   - Remove primary SPEED −0.2×2 effect identity and single-hit base 13 packaging.
   - Honest description: 3×5 M/L; on hit Exposed 2 → next ranged ATTACK +15% Setup.

2. **`resolveSkill` SIDE**
   - Multi-hit: 3 independent hit rolls; pay AP/CP; set cooldown/readyOnTurn.
   - If `hitsLanded >= 1`: plant `exposed` once (not per hit).
   - Full miss: no Exposed plant; damage 0.
   - No PUSH/PULL required; no Mode; no SPEED % debuff.

3. **Next ATTACK payoff (existing path)**
   - With `exposed` among ATTEMPT spent: RANGED ATTACK damage uses existing ×1.15; mark consumed at attempt (including full miss of that ATTACK).
   - MELEE ATTACK does not get ×1.15 from `exposed` (current T-023 contract — do not broaden unless free).
   - SIDE plays do not consume `exposed`.
