## Spec

### Must exist when done

1. **Authoring (`elbow_strike`)**
   - `cardRole: CardRole.SIDE_ATTACK`.
   - Costs: **AP 1**, **CP 0**, **CD 1**, HP 0.
   - `baseDamage: 8`; single hit; CLOSE; melee; TAIJUTSU/PHYSICAL tags as available.
   - `markEffects`: self mark id **`guard_break`**, duration **2**, `consume: ATTEMPT`, metadata **0.15** pen (stacks unused or constant). Prefer `targetActor: 'self'`.
   - Do **not** rely on SIDE `damageProperty: PIERCING` as the SOUL identity; prefer NORMAL unless tests need otherwise. Catalog payoff is next-ATTACK 15% def ignore.
   - Honest description: 8 dmg CLOSE; Guard Break 2 → next ATTACK ignores 15% defense.

2. **`resolveSkill` SIDE**
   - Pay costs; full hit → `damageDealt === 8` under test ports.
   - On **≥1 hit**: plant `guard_break` duration 2 on player.
   - On **full miss**: no plant; damage 0.
   - No Mode; no band move.

3. **Next ATTACK 15% pen**
   - When resolving `cardRole === ATTACK`, if `guard_break` is among own ATTEMPT marks spent this attempt and hitsLanded ≥ 1: apply **penetration 0.15** (or `Math.max(skill.penetration, 0.15)`) via existing pen helper + defense fixture (same pattern as Studied 0.2).
   - On full miss ATTACK: consume at attempt per SOUL own-mark rule; no pen bonus applied.
   - SIDE plays do not consume Guard Break for the pen payoff (only ATTACK).
   - Without `guard_break` and without skill-native pen: baseline damage with fixture defense unchanged.
   - Numeric AC: with defense fixture e.g. 50% and base 10 hit → without mark `floor(10*(1-0.5))=5`; with Guard Break `floor(10*(1-0.5*(1-0.15)))=floor(10*0.575)=5` wait — pick defense so difference is visible (e.g. def 0.4, base 20 → without 12, with pen 0.15 → floor(20*(1-0.4*0.85))=floor(20*0.66)=13).
