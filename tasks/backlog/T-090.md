## Spec

### Must exist when done

1. **Authoring (`lightning_ball`)**
   - `cardRole: CardRole.ATTACK`.
   - Costs: **AP 2**, **CP 5**, **CD 3**, HP 0 (catalog).
   - `baseDamage: 15`; `hitCount` default 1.
   - `allowedRanges: [CombatRange.MEDIUM, CombatRange.LONG]`.
   - `modeInteraction`:
     - `modeId: 'sharingan_3'`
     - `family: MODE_FAMILY.SHARINGAN` (or equivalent)
     - `consumeCharges: 1`
     - `damageMultBonus: 0.4`
     - **No** `requireOn` (base legal when Mode OFF).
   - Stun honesty: **45% Stun 1** on impact (HARD_CONTROL mark or STUN effect — lock one path; prefer same control path as other 45% stuns if present).
   - Tags: NINJUTSU / LIGHTNING as available.
   - Honest description: 15 dmg + 45% Stun 1; with Sharingan 3-Tomoe ON +40% and 1 charge at attempt.

2. **`resolveSkill` behavior** (reuse Mode enhance; no special-case id if possible)
   - Mode OFF: baseline damage under deterministic hit port; **no** charge spend.
   - Sharingan 3 ON with ≥1 charge: damage = `floor(baseline * 1.4)`; spend **1** charge at attempt; Mode stays ON if charges remain.
   - Sharingan **2** alone does **not** apply this row’s enhance.
   - On hit: roll Stun 1 at **0.45** (deterministic rng port for tests).
   - Invalid AP/range: reject, consume nothing.
   - Does **not** grant extra ranges beyond authored M/L (unlike Chidori MEDIUM grant).

3. **Compose**
   - Mirror Fireball/Dragon Flame field shape; only mode id, mult, and Stun package differ.
   - Do not retune Chidori 2-charge / MEDIUM grant.
