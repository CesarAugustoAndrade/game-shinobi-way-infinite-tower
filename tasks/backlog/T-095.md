## Context

Air Bullet chips with PUSH and ACC debuff. Great Breakthrough should be the **wind ATTACK** that deals **16** at M/L, **PUSH 1 on hit**, and adds **+20% Setup damage** only when the forced PUSH **actually changes** the band (PUSH@LONG = no move, no +20%).

## Spec

### Must exist when done

1. **Authoring (`great_breakthrough`)**
   - `cardRole: CardRole.ATTACK`.
   - Costs: **AP 3**, **CP 5**, **CD 3**, HP 0 (catalog; fix AP 2→3).
   - `baseDamage: 16`; `hitCount` default 1.
   - `allowedRanges: [CombatRange.MEDIUM, CombatRange.LONG]`.
   - `bandMove: { kind: 'PUSH', steps: 1, requireHit: true }`.
   - Conditional Setup mult: **+0.20** when PUSH results in `moved === true` (document field e.g. `setupMultIfBandMoved: 0.2` or equivalent resolved in pure path).
   - Remove primary ACC −25% debuff as identity.
   - Tags: NINJUTSU / WIND / MOVEMENT as available.
   - Honest description: 16 M/L; PUSH 1 on hit; +20% Setup if band changes.

2. **`resolveSkill` ATTACK**
   - Pay AP3/CP5/CD.
   - Hits ≥1: apply PUSH 1; voluntary move flag unchanged.
   - Damage: baseline 16 under hit port when `moved === false` (e.g. cast from LONG pushing further is boundary — LONG+PUSH = no move).
   - When hits ≥1 and PUSH **moves** the band: damage uses Setup mult **+20%** → `floor(baseline * 1.2)` (T-018 floor style); Setup bucket separate from Mode enhance (none here).
   - Miss: no PUSH, no Setup mult.
   - No Terrain/Heat.

3. **Compose**
   - Reuse existing PUSH motor; only add conditional Setup mult when `moved` (may require applying damage after forced move or pre-check shift outcome — document order; prefer: compute would-move → apply mult → commit hits → commit move, or hit damage after move with same floor).
   - Do not invent ACC % debuff.
