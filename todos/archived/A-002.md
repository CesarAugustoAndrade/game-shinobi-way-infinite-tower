## Objetivo

Drops de ítems en combate normal (Broken mínimo). Cablear pasivas rotas (pierce, DR, all-elements, convert, below_half_hp). Alinear elite EPIC vs craft RARE.

## Criterios de hecho

- [x] Combate puede dropear componentes
- [x] Pierce/DR/etc. afectan daño real
- [x] Elite no trivializa craft

## Qué se hizo

1. **Combat drops** (`useCombatVictory` + `App.handleRewardClose`):
   - 40% chance (`LOOT_BALANCE.COMBAT_ITEM_DROP_CHANCE`) to drop Broken component via `generateLoot`
   - After XP/ryo reward modal, LOOT screen opens if drops exist
2. **Artifact passives wired into live combat**:
   - `PIERCE_DEFENSE` (permanent + on_crit) → `calculateDamage` defense scaling
   - `DAMAGE_REDUCTION` (+ `below_half_hp`) → enemy hit mitigation (`EnemyTurnSystem`, sim)
   - `ALL_ELEMENTS` → force 1.2× SE multiplier
   - `CONVERT_TO_ELEMENTAL` → split PHYSICAL vs elemental defense
3. **Elite / free artifacts → RARE** (`generateRandomArtifact`): matches craft `synthesize()`; EPIC only via 2× RARE upgrade
