## Objetivo

Alinear BattleSimulator/CombatSimulationService con PlayerTurn/EnemyTurn y EnemySystem. Approaches en CLI o apagar flag.

## Criterios de hecho

- [x] Misma fuente de daño/turno o tests de paridad
- [x] 1v1 no usa scaling legacy sin caveat
- [x] Docs SIMULATION.md actualizados

## Qué se hizo (pragmatic scope)

1. **`generateSimEnemy`** → wraps `EnemySystem.generateEnemy` with forced archetype + floor→danger reverse map (`floorToApproxDanger`). Documented remaining diffs (name label, optional TANK thorns).
2. **Enemy AI** → `BattleSimulator.executeEnemyTurn` uses `EnemyAISystem.selectEnemySkill` (live path).
3. **Approaches** → success chance + effects from `APPROACH_DEFINITIONS` / `calculateApproachSuccessChance`; first-hit **2.0×** (was 2.5 hard-coded); initiative from defs via `determineTurnOrder`; buffs/debuffs/HP cut from data.
4. **`SIMULATION.md`** → location + campaign modes, parity caveats table, prefer attrition modes for balance.
