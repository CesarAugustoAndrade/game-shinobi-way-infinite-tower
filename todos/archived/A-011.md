## Objetivo

Eventos pasan archetype TANK/ASSASSIN/BALANCED pero useActivityHandlers caste a NORMAL|ELITE|BOSS y generateEnemy trata el 3er arg como tipo de enemigo → arquetipo aleatorio. Mapear build archetype al arquetipo real de EnemySystem (o renombrar campo y documentar).

## Criterios de hecho

- [x] Evento con archetype ASSASSIN genera enemigo ASSASSIN (tendencia/tests)
- [x] Tipo ELITE/BOSS separado del arquetipo de stats
- [x] Test o invariante de contenido documentado

## Cambios

- `generateEnemy(..., forcedArchetype?)` — 6º arg opcional para combat build
- `export type EnemyArchetype` + `isEnemyArchetype`
- `useActivityHandlers`: maps `triggerCombat.archetype` → forcedArchetype; tier defaults NORMAL (`enemyType` optional)
- `types.ts` documents archetype vs enemyType
- Tests in `EnemySystem.test.ts` (forced ASSASSIN/TANK/CASTER)
