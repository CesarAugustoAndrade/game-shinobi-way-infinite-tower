## Objetivo

Kits ≥3 skills por arquetipo. Boss table por danger/región (no floors legacy). Telegraph de 1 turno. Opcional: chakra enemigo + self-buffs.

## Criterios de hecho

- [x] TANK/BALANCED no solo BASIC
- [x] Bosses nombrados por danger
- [x] Intent visible o log de next skill

## Entry points

- `src/game/systems/EnemySystem.ts` — `getArchetypeKit`, boss via `getBossData`, opening intent
- `src/game/systems/EnemyAISystem.ts` — `selectEnemySkillDecision` (skill + reason, honors intent)
- `src/game/systems/EnemyTurnSystem.ts` — uses/clears intent; sets next telegraph + log
- `src/game/constants/index.ts` — `BOSS_BY_DANGER` (1–7), `BOSS_BY_ARC`, `getBossData`
- `src/game/types.ts` — `intendedSkillId` / `intendedSkillName` / `intentReason` on `Enemy`
- `src/hooks/useCombat.ts` — combat-start log + persist intent after enemy turn

## Implementación

### Kits (≥3 skills / arquetipo)
| Archetype | Skills |
|-----------|--------|
| TANK | Taijutsu, Mud Wall, Brace, Strong Fist |
| ASSASSIN | Taijutsu, Shuriken, Smoke Bomb, Senbon |
| BALANCED | Taijutsu, Shuriken, Leaf Whirlwind, Water Clone |
| CASTER | Taijutsu + 2 elementales (por elemento del enemigo) |
| GENJUTSU | Taijutsu, Hell Viewing, Mind Disturbance, False Surroundings |

### Bosses
- `getBossData(danger, arc)` clampa danger a 1–7; overrides por arco (`WAVES_ARC`, `EXAMS_ARC`, …)
- Fallback `BOSS_BY_DANGER` (Demon Brothers → Pain)
- Ya no se usa el default *Edo Tensei Legend* por claves floor 8/17/25

### Telegraph
- Al generar: intent = primera skill no-basic
- Tras turno enemigo: AI elige next skill, se guarda en enemy + log `"X prepares Y..."`
- Siguiente turno: AI honra `intendedSkillId` si sigue off-CD
