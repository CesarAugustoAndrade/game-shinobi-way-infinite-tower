## Objetivo

Unificar precio UI vs buyItem (×1.8). Stock > Broken. Sell ratio desde BALANCE.SELL_PRICE_RATIO.

## Criterios de hecho

- [x] Precio mostrado = cobrado
- [x] Shop con rareza/quality
- [x] 0 hardcode 0.6 de sell en UI

## Cambios

- `buyItem`: `item.value * MERCHANT.ITEM_PRICE_MULTIPLIER * (1 - discount%)`
- `generateMerchantItem(floor, difficulty, treasureQuality)` — stock mix Broken/Common/Rare
- `getSellPrice()` + `BALANCE.SELL_PRICE_RATIO` en handlers/UI (Bag, EquipmentPanel, Loot, TreasureChoice, inventory/treasure handlers)
