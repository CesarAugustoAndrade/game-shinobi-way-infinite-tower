## Objetivo

Path único al completar location: markComplete + updateDeckAfterCompletion + evaluateIntel + drawLocationCards + locationsCleared++. Eliminar o redirigir GameState.EXPLORE sin UI.

## Criterios de hecho

- [x] Completar location redibuja cartas

- [x] locationsCleared avanza en vivo

## Implementación

Single path: `completeLocationAndReturnToRegion` in `useLocationCards`:
1. `markLocationComplete` (idempotent)
2. `exitLocation`
3. `updateDeckAfterCompletion`
4. `player.locationsCleared++` (once)
5. `evaluateIntel` + `drawLocationCards`
6. `GameState.REGION_MAP`

Wired from `returnToMap`, `returnToMapActivityComplete`, `handleLeaveLocation`, activity handlers, and reward close. All `GameState.EXPLORE` fallbacks → `LOCATION_EXPLORE` / `REGION_MAP`.
