---
description: Skill consolidation — merge, prune and re-version a skill that grew too big
---

Input: $ARGUMENTS = <skill-name>

Consolidation of a skill (skill `loop-engineering` →
references/skills-self-learning.md). Run periodically or when the SKILL.md passes
~300 lines. Steps:

1. Read SKILL.md + LEARNINGS.md + SCORES.md.
2. Merge redundant rules; promote patterns repeated across ≥3 tasks to a general
   rule; archive the obsolete.
3. Re-version: v1.x → v2.0 if something structural changes.
4. Keep every rule anchored to evidence (a task, an example). Better 10 anchored
   rules than 100 vague ones. Record the consolidation in LEARNINGS.md.

Rules and rubric anchors change only with the user's explicit OK: propose, don't
impose.
